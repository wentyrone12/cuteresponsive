# Little Love Notes ♡ — Aesthetic Challenge Edition

A mobile-first, replayable, standalone love-note website. No npm, backend, database, API key, or build step required.

## Use
1. Extract this ZIP and open `cuteresponsive-main/index.html` in your browser.
2. Try hovering near **No** on a laptop/PC. It jumps to random locations across the full screen and shrinks with each escape.
3. On mobile, tap **No** to make it move. Each dodge increases the counter; at 5 escapes a secret note appears.
4. Press **Yes** for the preserved original GIPHY GIF, confetti hearts, and the original `music.mp3`.
5. Press **Play again** to reset the chase, music, counter, and surprise.
6. Switch between Strawberry Milk, Lavender Dream, and Peachy Love with the three round theme buttons.
7. Use **Share** to open a styled share card and copy a hosted link (or an invite caption when opened as a local file).

## Share to friends / TikTok
Publish the folder using GitHub Pages, Netlify, or your preferred static host and copy the public link. On mobile, record the chase and capture a reaction to the secret note or the Yes screen. The share feature cannot turn a file:// URL on your computer into a publicly accessible website.

## Preserved media
- Original user images: `cute1.png`, `cute1-cropped.png`, `cute2.png`
- Original music: `music.mp3`
- Original GIPHY GIF URL: `https://media.giphy.com/media/MDJ9IbxxvDUQM/giphy.gif`

The original GIF is remote (not included as a binary GIF in the original upload), so it requires internet access. If it fails to load, the included `cute2.png` shows automatically.

Native JavaScript alerts, confirms, and prompts are **not** used. All user feedback appears in designed UI elements.
